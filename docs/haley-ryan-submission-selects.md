## Why this gallery submits well
- Iconic, recognizable St. Louis location (Union Station Grand Hall, stained glass, skyline). Strong local angle for Saint Louis Bride.
- Clear narrative arc: lounge, architecture, corridor, golden hour, cocktails. Reads as a real date, which matches the "memory, not performance" brand.
- Built-in variety editors ask for: details (ring, cocktails, hands), scale shots, portraits, candid movement, and a BW thread throughout.

## Outlet fit for an engagement session
1. **Ruffled** (submissions@ruffledblog.com): accepts engagement shoots; gallery link + story + vendor list. Vendor list is short for a session: photography, venue (St. Louis Union Station Hotel), plus hair/makeup or styling if any.
2. **Saint Louis Bride** (bridestl.com/submit-your-wedding): local print, loves recognizable STL venues. Pick one of these two first; both prefer unpublished work.
3. **Wandering Weddings**: takes engagement submissions (80-100 images, 2400px JPEG) but requires membership.
