## 3. Image selection guide for the submission gallery (Penn vow renewal)

Curate **75–100 images**, mixed horizontal/vertical, in narrative order:
- 3–5 wide establishing shots of the venue/setting
- 10–15 details: invitations/signage, florals, table decor, cake/desserts, sentimental objects (original wedding photos, rings)
- 15–20 couple portraits (include golden hour if available)
- 15–20 ceremony/vow-renewal moments — prioritize genuine emotion (tears, laughter, hands held)
- 15–20 candids: guests, multi-generational family moments, kids, toasts
- 5–10 party/reception energy shots
- Skip: near-duplicates, heavy-crop images, anything under ~2400px on the long side

## 5. Repeatable workflow (the "automation")

Each time a gallery is delivered:
1. Within 2 weeks of delivery, curate 75–100 selects into a dedicated Pic-Time submission gallery.
2. Confirm with the couple/client that they're happy to be featured.
3. Match the shoot to the outlet (vow renewal/wedding → Ruffled or Saint Louis Bride; elopement → Wandering Weddings; local event → Sauce).
4. Copy the template above, fill the bracketed fields, send.
5. Log the submission date + outlet; wait out the response window (2 weeks Ruffled / 15 days Wandering) before submitting the same shoot elsewhere.
